## Capstones

- Persistent transactional KV engine (WAL, snapshots, MVCC)
- Distributed cache (TTL, eviction, replication)
- Distributed scheduler (leases, retries, fault recovery)
- Financial ledger and payments (idempotency, outbox)
- Dropbox-like file metadata service
- Real-time data streaming platform

## Progression (when relevant)

Requirements → simple implementation → optimal structures → concurrency → async/performance → persistence → distribution → operational readiness → Principal-level trade-offs.
